# Diretrizes de Acessibilidade (Frontend Streamlit)

O dashboard é uma página interna do Streamlit. O foco e o teclado pertencem aos widgets do framework. O conteúdo próprio do projeto segue estas regras:

1. **Contraste**: o tema escuro usa texto claro sobre fundo escuro. A margem não depende só de cor: o texto diz se ela é alta, média ou baixa.
2. **Cards**: cada oferta tem preço, margem, pontuação em escala de 100 e data. O botão de detalhes inclui o nicho, para o leitor de tela distinguir os cards.
3. **Texto**: o título não usa emoji decorativo.
4. **Vídeo**: a prévia tem a legenda "Prévia do vídeo do anúncio". A transcrição fica no mesmo diálogo.
5. **Links**: a loja abre em nova aba com `rel="noopener noreferrer"`.
